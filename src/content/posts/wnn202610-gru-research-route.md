这次参加 WNN202610 / Alfa Connectome，我的路线并不是模型越来越复杂、分数就越来越高。最初想让 GFlowNet 挖掘因子，再交给 GRU 预测；遇到效果和耗时问题后，又回到 GRU 本身，逐步尝试输入门控、残差思路和微调。

截至 2026 年 11 月 9 日，已经确认的最佳公开榜成绩来自 **Feature Gate GRU，分数为 0.65001**。后续已经准备了多项新实验，但尚不能把它们写成提分成果。

本文记录公开层面的研究路线与概念。比赛仍在进行中，代码、权重、因子公式和具体训练配方暂不公开；成绩以自己保存的实验记录和平台反馈为准，也不代表最终私榜成绩。

## 先理解任务，再讨论模型

这个比赛面对的是长序列市场事件。模型依次读取订单簿和交易相关特征，预测两个未来价格变化指标。任务形式和数据说明见[比赛官网](https://wundernn.io/)。

它与把一张表一次性送入回归器有两个明显区别。

首先，推理必须是因果的。预测当前行时只能利用当前和历史信息，不能借助后续行。独立序列之间也不能继承状态。其次，模型需要在规定的推理时间内处理大量数据，精度与部署成本必须一起考虑。

评分也不能简单用普通均方误差代替。比赛使用两个目标的全局加权 Pearson 相关性：按规定裁剪真实值和预测，以裁剪后的真实值绝对值作为权重，分别计算相关性后再取均值。验证时还要使用正确的计分掩码。

因此，我一直把三类结果分开看：训练内部留出、官方 valid 上的本地验证、官网公开榜。它们的数据范围不同，数值不能混在一起排名。全局相关性也不能用“每条序列相关性的平均值”代替。

## 第一阶段：让 GRU 成为可用的基线

GRU，即门控循环单元，是一种带记忆的循环神经网络。它逐步更新隐藏状态，在接收新输入的同时，决定保留多少历史信息。相关门控结构可以追溯到 Cho 等人的 [RNN Encoder–Decoder 论文](https://arxiv.org/abs/1406.1078)。

对这个任务来说，GRU 的吸引力在于：它天然支持逐行处理，同一个隐藏状态可以概括过去的信息，推理时不必重新计算整段历史。

项目早期的一份参考提交得到 **0.61753**。这一阶段的重点，是把数据读取、序列预热、状态切换、评分和提交接口跑通。有了能够在平台完成推理的版本，后续改动才有比较对象。

后来，纯 GRU 的一份混合损失版本在本地完整 valid 上得到 **0.671978**，官网公开榜为 **0.64318**。这组结果也提示我：本地验证分数与榜分之间存在差距，本地的增益需要经过官网反馈检验。

## 第二阶段：尝试 GFlowNet 挖因子，再交给 GRU

我当时的想法是，把“寻找表达式”和“利用时序信息预测”分成两个问题。

GFlowNet 负责搜索候选因子；筛选并固定因子后，将其作为额外输入交给 GRU。最终预测仍由 GRU 完成，推理阶段不再运行因子搜索，但需要逐行计算已经选中的因子。

GFlowNet 的通用目标，是学习生成高奖励且具有多样性的候选对象，而不是只找到一个最优对象。它本身并不保证某个金融因子具有稳定预测能力。原理可参考 [GFlowNet 原始论文](https://arxiv.org/abs/2106.04399)。

这条路线在探索阶段出现过局部改善，但完整提交暴露了两个问题：

- 一份 GFN＋GRU 提交耗时 **61 分 56 秒**，因超时未得到有效分数。
- 后续一份优化提交耗时 **57 分 37 秒**，公开榜分数为 **0.46799**，明显低于后来的纯 GRU 版本。

这不能单独证明“加速破坏了模型”，因为要归因，还需要核对训练权重、预处理、因子状态和优化前后的逐行输出是否等价。它能够支持的结论是：**当时这条完整实现没有成为值得继续投入的主线。**

回头看，这一步最容易忽视的是筛选目标与最终任务之间的距离。小样本上的因子奖励、短期相关性和加入 GRU 后的完整表现，并不是同一件事。因子还可能重复了 GRU 已经能提取的信息，却增加了逐行计算与维护状态的成本。

我因此把重心重新放回 GRU，先确认输入、训练和部署链路能带来什么。

## 第三阶段：Feature Gate GRU 在做什么

Feature Gate GRU 可以理解为在 GRU 前加入一个输入调节模块：先根据当前输入，为各个特征生成调节系数，再把调整后的特征交给 GRU 处理。

这里的 Feature Gate 与 GRU 内部的门不是一回事。GRU 内部的门控制隐藏状态如何更新；输入侧的 Feature Gate 则关注“当前应该如何使用这些输入特征”。前者处理记忆，后者处理输入表达。

与固定删除某些列相比，输入门控允许模型随输入状态改变特征的使用程度。它也不等于 GFlowNet 式的显式因子搜索：前者通过端到端训练学习调节方式，后者需要生成、筛选并维护额外表达式。

它仍有边界。一个特征获得较高门控权重，不代表它具有因果意义，更不能直接把权重解释成稳定的经济结论。输入门控也没有绕过数据质量或分布变化的问题。

这一阶段，我还尝试了趋势残差方向。两项实验都完成了官网提交，结果如下。

| 已确认版本 | 本地完整 valid WP | 官网公开榜 | 平台耗时 |
|---|---:|---:|---:|
| 纯 GRU 混合损失版本 | 0.671978 | 0.64318 | 23 分 32 秒 |
| Trend Residual 版本 | 0.677321 | 0.64784 | 42 分 42 秒 |
| Feature Gate GRU | **0.679468** | **0.65001** | **27 分 36 秒** |

这些是对应运行的结果，并不构成只改变一个模块的严格因果证明。它们至少说明，在当时的完整方案中，Feature Gate 取得了更好的已确认榜分，同时保持了比趋势残差版本更短的推理耗时。

Feature Gate 相比纯 GRU 的榜分提高了 **0.00683**。这不是一个可以无限外推的增益，但足以让它成为后续工作的固定基准。

## 支线实验：加噪、树模型和残差结构

主线确定以后，我也探索过几条支线。

输入加噪的出发点是正则化，希望模型不要过度依赖某些细小的输入波动。不过市场特征包含离散取值、重复值和特殊编码，不能把所有列都当作连续变量统一扰动。已有的小范围配对实验只出现很小的分数变化，没有形成足够稳定的证据，因此暂时不能说“加噪能提分”。

树模型方向测试了 LightGBM，以及后续的 CatBoost。树单模没有成为更强的替代方案；与较强 GRU 的融合也没有表现出明确、稳定的净收益。部分全量训练尝试还遇到了资源或执行问题，失败的运行不能算成完成的负面模型结果。

残差 GRU 方向则已有训练和本地验证产物，但目前这份记录中，没有足够的官网结果证明它超过了已确认的 Feature Gate 基准。

这些尝试没有白做。它们帮助我区分两件事：一个方法是否能独立拟合信号，以及它是否提供了基准模型尚未利用的信息。第二个问题才决定它值不值得成为额外分支或融合成员。

## 第四阶段：从增加模块转向微调已有模型

在已经有可用基准之后，继续训练一个全新复杂模型并不是唯一选择。另一条路线是保留已经学到的表示，用较小更新调整部分参数，观察模型能否在不增加推理结构的情况下改善预测。

当前准备的低学习率微调版本，从已经确认的 Feature Gate 权重开始，保留部分模块，更新上层时序表示与预测部分。这是一项新实验，**目前还没有新的榜分可以写成成果**。

这里也要区分“用全部训练数据”与“训练全部参数”。使用全部 train，不意味着必须解冻模型的每一层；只更新部分参数，也仍然可以遍历全部训练数据。

工程上，微调需要重新计算当前权重下的前向结果。若被更新的网络发生了变化，旧模型的预测缓存就不能代替它的新前向。加载已有模型后新建优化器，也不等于恢复原训练优化器的完整状态。

为了让实验能够继续推进，后续代码加入了阶段性 checkpoint 和自动导出：保存模型、优化器与训练进度；训练完成即生成独立提交包；导出失败时尽量只恢复导出，不重复训练。训练速度、显存占用和提交推理时间，是三个需要分别测量的问题。

## 现在的进度，以及下一步如何判断

截至本文更新时，路线可以概括为：

| 阶段 | 当前能够确认的结论 |
|---|---|
| GRU 基线 | 已建立可用的训练、验证与提交链路 |
| GFN＋GRU | 当时实现遇到耗时与效果问题，未保留为主线 |
| Feature Gate GRU | 已确认公开榜 0.65001，作为后续基准 |
| 加噪与树模型融合 | 尚无足够稳定的证据支持替换基准 |
| 低学习率微调 | 代码与导出流程已准备，等待实际训练及官网反馈 |
| 浅层 GRU 与时序训练新配方 | 顺序实验代码已准备，尚无新榜分 |

新的方向包括浅层 GRU 配合更充分的预测头，以及显式历史变化、记忆管理和分阶段训练。它们受到其他参赛分享启发，但“别人有效”只足以提出假设，还不能替代自己的对照实验。

接下来我会保留原 Feature Gate 提交作为参照，先看新版本是否在相同数据和评分口径下改善，再结合官网反馈判断。候选方法若改变了训练数据覆盖，就需要单独标注；如果用一部分 valid 参与微调，参与训练的那部分就不能再被当作独立验证集。

这段探索让我更重视一条朴素的研究习惯：把模型想法、训练完成、本地改善、成功提交和榜分提升分别记录。这样，即使一条复杂路线最终被放弃，留下的结论也能用于下一次实验。
